Kebijakan Privasi AkuIslam

Terakhir diperbarui: 18 November 2026

Ringkasan: AkuIslam tidak mengumpulkan data pribadi apa pun. Aplikasi bekerja sepenuhnya offline dan tidak mengirim data ke server mana pun.

1. Data yang kami kumpulkan

AkuIslam tidak mengumpulkan, mengirim, atau menyimpan data pribadi ke server. Tidak ada akun, tidak ada pendaftaran, tidak ada analitik, pelacakan, maupun iklan.

2. Data yang disimpan di perangkat Anda

Bookmark dan riwayat baca disimpan secara lokal di penyimpanan privat aplikasi pada perangkat Anda. Data tersebut tidak pernah dikirim keluar perangkat, dan akan terhapus bila Anda menghapusnya dari dalam aplikasi atau menghapus aplikasi.

3. Koneksi jaringan

Seluruh teks Al-Qur'an, terjemahan, serta data surah sudah tersedia di dalam aplikasi. AkuIslam tidak menggunakan koneksi internet dan tidak meminta izin jaringan.

4. Izin aplikasi

AkuIslam tidak meminta izin apa pun. Aplikasi tidak mengakses:

  • kamera atau mikrofon,
  • lokasi,
  • kontak,
  • penyimpanan eksternal atau file pengguna.

5. Pihak ketiga

Kami tidak membagikan data pengguna kepada pihak mana pun. Teks Al-Qur'an dan terjemahannya bersumber dari equran.id dan Kementerian Agama Republik Indonesia, yang datanya disertakan di dalam aplikasi tanpa koneksi ke layanan tersebut.

6. Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data dari anak-anak.

7. Perubahan kebijakan

Perubahan atas kebijakan ini akan diperbarui pada halaman ini beserta tanggal pembaruannya.

8. Kontak

Pertanyaan mengenai kebijakan privasi dapat dikirim ke 11231036@student.itk.ac.id.
